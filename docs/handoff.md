## 发布注意事项

- 本文件为公开仓库可发布摘要，不记录客户现场 IP、账号、路径、真实邮箱、真实密钥或现场数据库名。
- 客户现场实施细节应保存在私有部署记录或私有知识库中，不应提交到公开 GitHub 仓库。
- 运行配置必须通过环境变量、私有 `.env`、数据库或管理员后台保存。
- 新增连接器时应提供通用占位配置和测试用例，不提交真实凭据。
