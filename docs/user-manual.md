# Ant Colony 使用指南 — 写给同事的 AI 助手说明书

**版本**: v2.0 | **更新**: 2026-06-09

---

## 📖 这份指南是给谁看的？

如果你不是程序员、不懂代码、之前没用过 AI 工具，**这份指南就是为你写的**。读完它，你就能用好公司的 AI 助手。

---

## 一、这是什么？

Ant Colony 是一个 **企业 AI 助手平台**。你可以把它理解为：

> **一个 24 小时在线的智能同事，你可以随时在企微聊天里找它帮忙。**

它能帮你做这些事：
- 回答公司相关的问题
- 帮你查找同事的联系方式
- 查看和管理你负责的任务
- 搜索公司里的文档和知识
- 查看日程安排、创建会议
- 帮你写文档、周报
- 处理 PDF 文件
- 从网盘同步文件
- 等等（下面会详细说）

---

## 二、在哪能找到 AI 助手？

AI 助手就在你每天都在用的**企业微信**里。

### 在企微里找到 AI 助手

1. 打开企业微信
2. 在左侧找到 **「德源AI助手」**（或公司设置的 AI 机器人名称）
3. 点击进入聊天窗口
4. 直接打字发送即可

当前支持的平台：
- ✅ **企业微信** — 最常用，直接聊天
- 📌 飞书 / 钉钉 / Telegram — 如果公司开通了也能用

---

## 三、怎么用？像聊天一样简单

**不需要学任何新操作**，就像和朋友聊天一样：

```
你：帮我查一下市场部的负责人是谁
AI 助手：市场部负责人是 xxx
```

```
你：我今天有什么任务？
AI 助手：你有 3 个待完成的任务...
```

### 几个聊天技巧

| 技巧 | 说明 |
|------|------|
| **直接说就行** | 不用学命令格式，像平常说话一样讲 |
| **说得越清楚越好** | "帮我查一下 xxx" 比 "查一下" 更容易得到准确答案 |
| **可以追问** | 可以接着上一个问题继续问 |
| **可以换角色** | 如果说"换个角色"，AI 会换一种专业身份来帮你 |
| **发文件也可以** | 直接发 Word / PDF / Excel 文件给 AI，它能帮你整理内容 |

## 四、AI 助手能做什么？（完整功能清单）

### 📋 任务管理

AI 可以帮你管理工作任务。在群聊中，它会自动识别出需要完成的事项并生成任务。

**示例：**

```
你：查看我的任务
AI：(列出你负责的所有任务及状态)
```

```
你：把这个任务标记为已完成
AI：好的，已更新任务状态
```

常用操作：

| 你说 | 效果 |
|------|------|
| 查看我的任务 | 列出你所有任务 |
| 创建一个任务叫"准备季度报告" | 创建新任务 |
| 完成任务 xxx | 把任务标记完成 |
| 把任务设为高优先级 | 提高任务重要性 |
| 搜索任务 季度报告 | 搜索特定任务 |
| 查看任务统计 | 看整体完成情况 |

## 六、常见问题

### Q：AI 助手不认识我怎么办？
第一次使用时，AI 知道你的身份（来自企微账号），不需要额外登录。

### Q：我说了但没有反应？
- 确认发消息的对象是 AI 助手（在 AI 助手的聊天窗口里）
- 如果是群聊，需要 @AI 助手的名字
- 网络是否正常

### Q：AI 回答的不对怎么办？
- 可以追问："不是这个意思，我是想问..."
- 或者换个说法重新提问
- 如果角色不对，说"换一个角色"

### Q：我能发文件给 AI 吗？
可以，直接在企业微信聊天窗口发送文件就行。支持：Word、PDF、Excel、PPT。

### Q：谁可以看到我的聊天记录？
AI 助手在你的私聊窗口里的对话只有你自己能看到。在群聊里的对话，群内成员都可以看到。

### Q：知识库的文档谁都能看吗？
不是的。公司知识库全公司可读，部门知识库本部门可读，个人知识库只有你自己和管理员能看。

### Q：隐私安全吗？
系统部署在公司内部服务器上，数据不出公司网络。所有 AI 处理都在公司内部完成。
